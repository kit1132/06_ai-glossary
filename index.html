06

4社に共通することば

安定

どのツールを使っても出てくる言葉です。上の検索窓でも絞り込めます。

まず知っておく

トークンToken
文章を区切る処理の単位。日本語では1文字から数文字で1トークンです。料金はこの数で決まります。
コンテキストウィンドウContext window
一度に読み込める最大の量。「短期記憶の広さ」だと考えてください。これを超えると前の話を忘れます。
ハルシネーションHallucination
もっともらしい嘘を生成すること。文章が自然なほど気づきにくいので、事実は必ず確認してください。
知識カットオフKnowledge cutoff
学習データの締切時点。それ以降のできごとは、検索させないかぎり知りません。
プロンプトPrompt
AIに与える指示文のこと。
マルチモーダルMultimodal
文章だけでなく画像や音声も扱えること。

使いこなす

システムプロンプトSystem prompt
会話の前に置かれる、振る舞いを決める指示。各社の「カスタム指示」がこれにあたります。
思考の連鎖Chain of Thought
いきなり答えさせず、段階を踏んで考えさせる指示の出し方。
グラウンディングGrounding
検索結果や社内文書など、実在する情報にもとづいて答えさせること。ハルシネーション対策の基本です。
RAG（検索拡張生成）Retrieval-Augmented Generation
社内文書などをまず検索し、その結果を読ませてから答えさせる仕組み。
コンテキストエンジニアリングContext engineering
指示文だけでなく「何を読ませるか」を設計する技術。長い作業ではこちらが効きます。
非決定性Non-determinism
同じ質問でも毎回答えが変わる性質。不具合ではありません。

外とつなぐ

エージェントAgent
目標を渡すと、自分で手順を決めて実行するAI。2026年の各社の主戦場です。
MCPModel Context Protocol
AIと外部ツールをつなぐ共通規格。「AIのUSB-C」と呼ばれます。Anthropic が公開し、現在は Linux Foundation が管理しています。
A2AAgent2Agent
別々の会社が作ったエージェント同士が協力するための規格。Google が公開しました。
コネクタConnector
Gmail や Slack など、外部サービスとつなぐ接続口。
ツール利用Tool use / Function calling
AIに外部の機能を呼び出させる仕組み。検索や計算はこれで実現しています。
APIApplication Programming Interface
アプリの画面を通さず、自分のプログラムからAIを呼び出す窓口。使った分だけの従量課金です。

気をつける

「推論」は2つの意味があるInference / Reasoning
Inference＝AIを動かして答えを出すこと（実行）。Reasoning＝答える前に考えること（思考）。同じ訳語なので、文脈で見分けてください。
プロンプトインジェクションPrompt injection
Webページや資料に仕込んだ指示でAIを乗っ取る攻撃。AIに読ませる資料の出どころに注意してください。
オプトアウトOpt-out
入力したデータを学習に使わせない設定。個人向けプランは使われる場合があり、法人向けは既定でオフのことが多いです。必ず設定画面で確認してください。
ガードレールGuardrails
危険な出力を防ぐ仕組み。断られたときはこれが働いています。
SynthID
Google が生成物に入れる、目に見えない電子透かし。AIが作ったかどうかの判別に使われます。
C2PA / Content Credentials
画像や動画の出どころと編集履歴を、署名付きで記録する業界標準。
その言葉は見つかりませんでした。ひらがな・カタカナ・英語を変えて試してください。

日本で仕事に使うときのルール

中期

海外の規制より先に、国内の枠組みを押さえてください。

名称 内容
AI推進法2025年9月1日に全面施行。罰則のない推進型の法律です。これに基づくAI基本計画は2025年12月23日に閣議決定され、適正性確保指針（2025年12月19日）も決まりました。
著作権法 30条の4AIの学習に著作物を使うことは原則として許諾不要。ただし「著作権者の利益を不当に害する場合」は例外です。2026年時点で条文の改正はありません。
文化庁「AIと著作権に関する考え方について」2024年3月公表。学習の段階と生成・利用の段階を分けて考えること、生成物が既存の作品に似すぎていないか確認することを求めています。
AI事業者ガイドライン総務省・経産省。第1.2版（2026年3月）。法的な拘束力はありませんが、事故が起きたときの責任判断に影響しうるものです。
EU AI Act（EUと取引がある場合）2026年7月27日に改正法が発効。高リスクの義務は延期され、単独型（附属書III）は2027年12月2日、製品組込型（附属書I）は2028年8月2日になりました。生成AIの利用者に最も関係するのは、AI生成物であることを開示する透明性の規定（第50条）で、こちらは2026年8月2日から適用が始まっています。

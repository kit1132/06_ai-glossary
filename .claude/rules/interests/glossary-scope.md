# スコープ

対象は ChatGPT / Gemini / Claude / Microsoft Copilot の**コンシューマ向け呼び名**と、日本で仕事に使うときの日付付きルール。

## 直す

- 既存セルの公式名
- 提供終了（`chip-x`）
- 個人向け料金（米ドル月額）
- モデル世代名（§03）
- §07 の施行日・ガイドライン版

## 足す

- 既存の「やりたいこと」行に対応する新名称
- §05 の改名行（昔の名前 → 今の名前。時期が公式で分かるもの）
- 新しい「やりたいこと」行は、**4社のうち2社以上**に公式名があるときだけ

## 残す

表にあるリサーチプレビュー／ベータは、公式が GA または終了と書くまで消さない。

例: Claude Design（リサーチプレビュー）

## 無視

- 噂、リーク、内部コードネームの新規追加
- ニュース記事の意訳
- 開発者向け API だけの名称（コンシューマ画面に出ないもの）
- 01_ai-news 系ダイジェストを根拠にした変更

## 4社の外

Cursor / Devin 等は対象外。Copilot 列の GitHub Copilot は「別製品」注記がある既存セルのみ維持する。

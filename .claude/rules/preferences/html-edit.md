# index.html の編集規則

## 触ってよい

- §02 対応表の `span.term` / `span.gloss`。終了は既存どおり `<span class="chip-x">提供終了</span>` を付ける
- §03 モデル名の `term` / `gloss`
- §04 料金のプラン名と `span.price`、stamp 内の注意書き（公式で確認できた範囲）
- §05 の `tbody tr` 追加（列構成は昔の名前 / 今の名前 / 時期・注記）
- §06 の既存 `.def` の定義文。新語は公式で定着したものだけ `.def` を追加
- §07 の日付付き事実
- 表紙 `.eyebrow`（`Quick Reference / YYYY.MM`）と `.mast-meta` の `情報取得時点`
- `.tally-mx` 集計表の数字だけ（§00「はじめに」の中。数え方は下）

`情報取得時点` は、`index.html` を変えた実行だけ実行日の JST に更新する。HEARTBEAT では表紙日付を動かさない。

## 触ってはいけない

- `<style>` と印刷用 CSS
- byline（X リンク、アイコン）
- 末尾 `<script>`（検索・印刷・HTML保存）
- `.brand` の data URI
- レイアウト用 class（`tbl` / `h-v` / `data-v` / `data-row` の付け方）
- §00 の案内文（ケース案内・読み方）
- 表紙標本（`.specimen`）の復活
- `&#x2060;` と `.nowrap`（語句の途中で折らないための印。本文を書き換えるときも残す）

## マークアップ

既存のセルに合わせる。

```html
<td data-v="v1"><span class="term">名前</span><span class="gloss">読み・注記</span></td>
```

日本語だけの名称は既存どおり `class="term ja"`。名称が無いセルは `span.gloss` だけ、または `span.none`。新しい class を発明しない。

## 件数の数え方

集計表はハードコード。変更後に数え直して数字を合わせる。やりたいことは行数なので会社別には分けない。4社の呼び名は `span.term` があるセルを数え、提供終了でも term があれば含める。

| 区分 | 数え方 |
|---|---|
| やりたいこと | §02（見出し「やりたいこと → 4社の呼び名」）の `tbody tr` 数。会社別には分けない |
| 4社の呼び名 | 同表で `span.term` があるセル数。提供終了でも term があれば数える。「専用名称なし」や gloss だけのセル、`span.none` は数えない |
| 共通のことば | §06 の `div.def` 数。会社別には分けない（4社の製品名ではない） |
| 改名の記録 | §05 の `tbody tr` 数 |
| 合計 | 上4つの和 |

基準値（2026-08-17 時点）: 17 / 64 / 24 / 12 / 117

# index.html の編集規則

## 触ってよい

- §02 対応表の `span.term` / `span.gloss`。終了は既存どおり `<span class="chip-x">提供終了</span>` を付ける
- §03 モデル名の `term` / `gloss`
- §04 料金のプラン名と `span.price`、stamp 内の注意書き（公式で確認できた範囲）
- §05 の `tbody tr` 追加（列構成は昔の名前 / 今の名前 / 時期・注記）
- §06 の既存 `.def` の定義文。新語は公式で定着したものだけ `.def` を追加
- §07 の日付付き事実
- 表紙 `.eyebrow`（`Quick Reference / YYYY.MM`）と `.mast-meta` の `情報取得時点`
- `.tally-mx` 集計表の数字（§00「はじめに」の中。数え方は下）
- `span.chip-new`（New バッジ）の付け外し。付け方と外す時期は下

`情報取得時点` は、`index.html` を変えた実行だけ実行日の JST に更新する。HEARTBEAT では表紙日付を動かさない。

## 触ってはいけない

- `<style>` と印刷用 CSS
- byline（X リンク、アイコン）
- 末尾 `<script>`（検索・印刷・HTML保存）
- `.brand` の data URI
- レイアウト用 class（`tbl` / `h-v` / `data-v` / `data-row` の付け方）

## マークアップ

既存のセルに合わせる。

```html
<td data-v="v1"><span class="term">名前</span><span class="gloss">読み・注記</span></td>
```

日本語だけの名称は既存どおり `class="term ja"`。名称が無いセルは `span.gloss` だけ、または `span.none`。新しい class を発明しない。

## New バッジ

直前の更新で新しく入った項目に `<span class="chip-new">New</span>` を付ける。読者が「今回どこが増えたか」を一目で追えるようにするため。

### 付け外しの順番

`index.html` を変更する回では、**必ずこの順で行う**。

1. 既存の `chip-new` を**すべて削除する**（前回付けた分を消す）
2. その回で**新しく追加した項目だけ**に付け直す

HEARTBEAT では触らない。表を変えない回なので、前回の New はそのまま残る。

### 付ける対象

その回で**増えた**もの。

- §02・§03 で新しく追加した `span.term`
- §05 で追加した `tbody tr`
- §06 で追加した `div.def`

既存セルの**値を直しただけ**（改名、金額改定、提供終了の追記）には付けない。増えていないため。

### 置き場所

`term` があるセルは、`term` の**内側の末尾**に入れる。`.term` は `display:block` なので、外に出すとバッジだけ次の行に落ちる。

```html
<td data-v="v1"><span class="term">新しい名前<span class="chip-new">New</span></span><span class="gloss">注記</span></td>
```

`term` が無い場所（§05 の `td`、§06 の `.def`）は、該当テキストの直後にそのまま置く。

### 注意

- CSS の `.chip-new` は定義済み。ルーチンでは span の付け外しだけを行い、`<style>` は触らない
- 件数には数えない。`span.term` の数は変わらないので、集計表の数字はバッジの有無に影響されない
- 末尾 `<script>` の検索は行の `textContent` を見るため、「new」で検索するとバッジの付いた行が絞り込める。副作用だが実害はない

## 件数の数え方

集計表はハードコード。変更後に数え直して数字を合わせる。やりたいことは行数なので会社別には分けない。4社の呼び名は `span.term` があるセルを数え、提供終了でも term があれば含める。

| 区分 | 数え方 |
|---|---|
| やりたいこと | §02（見出し「やりたいこと → 4社の呼び名」）の `tbody tr` 数。会社別には分けない |
| 4社の呼び名 | 同表で `span.term` があるセル数。提供終了でも term があれば数える。「専用名称なし」や gloss だけのセル、`span.none` は数えない |
| 共通のことば | §06 の `div.def` 数。会社別には分けない（4社の製品名ではない） |
| 改名の記録 | §05 の `tbody tr` 数 |
| 合計 | 上4つの和 |

基準値（2026-08-17 時点）: 17 / 64 / 24 / 12 / 117
